# Introduction to Deep Learning

## Raw notes
- Lecture: #L01

### Overview of Deep Learning
- **Representation Learning**: A subset of machine learning where models automatically discover the features and representations needed for a task directly from raw data, rather than relying on manual feature engineering.
- Quote: *"Representation learning is a set of methods that allows a machine to be fed with raw data and to automatically discover the representations needed..."* — LeCun, Y., Bengio, Y., & Hinton, G. (2015). Nature.

### Neural Network Families
- **Convolutional Neural Networks (CNNs)**: Introduced in the late 1980s / 1990s (e.g., LeNet-5). They incorporate spatial locality and weight sharing to capture local patterns and reduce parameter count.
- **Recurrent Neural Networks (RNNs)**: Designed for sequential data by using recurrent connections (backpropagation through time). They suffer from vanishing/exploding gradients, which are typically addressed by LSTMs.
