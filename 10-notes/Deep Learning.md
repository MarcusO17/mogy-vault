# Deep Learning

**Deep Learning** is a subfield of machine learning based on artificial neural networks. It is characterized by **representation learning** (or feature learning) with multiple levels of abstraction.

Unlike traditional machine learning methods that require manual feature engineering, deep learning algorithms allow a system to be fed raw data (such as pixels or raw text) and automatically learn the optimal representations necessary for classification or regression. Stacking multiple non-linear layers allows the network to learn increasingly abstract hierarchical features (e.g., edges $\to$ textures $\to$ object parts $\to$ whole objects).
