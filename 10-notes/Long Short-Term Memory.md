# Long Short-Term Memory

**Long Short-Term Memory** (LSTM) is a specialized recurrent neural network (RNN) architecture designed to capture long-range dependencies in sequential data. It introduces a gating mechanism and a constant error carousel (the cell state) to mitigate the [[Vanishing Gradients]] problem common in standard [[Recurrent Neural Networks|RNNs]].

---

## LSTM Architecture & Gates

An LSTM cell processes input $\mathbf{x}^{\langle t \rangle}$ and previous hidden state $\mathbf{h}^{\langle t-1 \rangle}$ at time step $t$ using three gates to control the flow of information:

### 1. Forget Gate ($f_t$)
Controls what information from the previous cell state should be discarded:
$$
f_t = \sigma(\mathbf{W}_{fx}\mathbf{x}^{\langle t \rangle} + \mathbf{W}_{fh}\mathbf{h}^{\langle t-1 \rangle} + \mathbf{b}_f)
$$
where $\sigma$ is the [[Sigmoid Function]], mapping outputs to $[0,1]$.

### 2. Input Gate ($i_t$) & Candidate Cell State ($\tilde{\mathbf{c}}^{\langle t \rangle}$)
Determines which new information should be added to the cell state:
$$
i_t = \sigma(\mathbf{W}_{ix}\mathbf{x}^{\langle t \rangle} + \mathbf{W}_{ih}\mathbf{h}^{\langle t-1 \rangle} + \mathbf{b}_i)
$$
$$
\tilde{\mathbf{c}}^{\langle t \rangle} = \tanh(\mathbf{W}_{cx}\mathbf{x}^{\langle t \rangle} + \mathbf{W}_{ch}\mathbf{h}^{\langle t-1 \rangle} + \mathbf{b}_c)
$$
Here, $\tilde{\mathbf{c}}^{\langle t \rangle}$ is a vector of new candidate values generated by a hyperbolic tangent activation.

### 3. Cell State Update ($\mathbf{c}^{\langle t \rangle}$)
Updates the old cell state $\mathbf{c}^{\langle t-1 \rangle}$ to the new cell state $\mathbf{c}^{\langle t \rangle}$ by scaling the old state with the forget gate and adding the candidate state scaled by the input gate:
$$
\mathbf{c}^{\langle t \rangle} = f_t \odot \mathbf{c}^{\langle t-1 \rangle} + i_t \odot \tilde{\mathbf{c}}^{\langle t \rangle}
$$
*(where $\odot$ denotes element-wise multiplication)*

### 4. Output Gate ($o_t$) & Hidden State Output ($\mathbf{h}^{\langle t \rangle}$)
Controls what parts of the updated cell state are passed to the hidden state (and output):
$$
o_t = \sigma(\mathbf{W}_{ox}\mathbf{x}^{\langle t \rangle} + \mathbf{W}_{oh}\mathbf{h}^{\langle t-1 \rangle} + \mathbf{b}_o)
$$
$$
\mathbf{h}^{\langle t \rangle} = o_t \odot \tanh(\mathbf{c}^{\langle t \rangle})
$$

---

## Integration in Recurrent Networks
In a deep RNN, standard recurrent units are replaced by LSTM cells. The persistent cell state $\mathbf{c}^{\langle t \rangle}$ acts as an information highway, allowing gradients to flow backward through time with minimal attenuation (preventing vanishing gradients).
