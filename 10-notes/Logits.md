# Logits

In deep learning, **logits** refer to the raw, unnormalized vector of predictions generated by the last layer of a neural network before it is passed to an activation function (such as [[Softmax]] or [[Sigmoid Function]]).

Mathematically, for a layer with weights $\mathbf{W}$ and bias $\mathbf{b}$ applied to input vector $\mathbf{x}$:
$$
\mathbf{z} = \mathbf{W}\mathbf{x} + \mathbf{b}
$$
Here, $\mathbf{z}$ represents the vector of logits. Applying a function like softmax converts these raw scores into a probability distribution:
$$
\mathbf{a} = \text{Softmax}(\mathbf{z})
$$
