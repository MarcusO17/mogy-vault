# L1.0 - SR




1. Machine Learning and AI is different from each other, making deep learning a sub category of both.
2. Machine Learning includes generalized linear models, tree-based methods, "shallow" networks, support vector machines, nearest neighbours and more.
3. AI on the other hand, is made up of symbolic expressions, logic rules/"hand-crafted" nested if-else programming statements.
4. Not all AI systems involve Machine Learning, for example, Deep Blue, which is a chess bot, does not use any sort of Machine Learning but instead many alpha-beta searches in parallel
