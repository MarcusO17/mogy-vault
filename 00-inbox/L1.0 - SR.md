# L1.0 




1. Machine Learning and AI is different from each other, making deep learning a sub category of both.
2. Machine Learning includes generalized linear models, tree-based methods, "shallow" networks, support vector machines, nearest neighbours and more.
3. AI on the other hand, is made up of symbolic expressions, logic rules/"hand-crafted" nested if-else programming statements.
4. Not all AI systems involve Machine Learning, for example, Deep Blue, which is a chess bot, does not use any sort of Machine Learning but instead many alpha-beta searches in parallel
5. AI is like something that uses rules, it's a non-biological system that is intelligent through rules.
6. ML are algorithms that learn/models/representations/rules automatically from data/examples
7. Deep Learning parameterize multilayer neural networks that learn different representations of data using abstraction layers.
8. AI In this case can be reffered as Symbolic AI
	1. Symbolic AI  (1950s-1980s)
	2. Statistical machine learning (1990s-2010s)
	3. [[Connectionism]] and deep learning (1940s-present)
		1. Wow this is interesting, Connectionism treats intelligence as a *emergent* property, Usually of large networks of simple adaptive units
		2. Its defining strength is **representation learning**
		3. Connectionism is the architectural foundation of modern AI because it frames intelligence as an emergent property of learnable networks of interacting units. Its enduring contributions are three: that knowledge can be held in **distributed representations** rather than discrete symbols, that learning is the **adaptive modification of connections**, and that complex behaviour can emerge from large-scale interaction among simple components. Contemporary deep learning is not a departure from these ideas but their largest-scale realisation.
