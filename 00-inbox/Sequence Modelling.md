# Sequence Modelling

## Types of Sequence Modelling Tasks.

1. Many-To-One
   - ![[Pasted image 20251202150504.png]]
   - The Input data is a sequence but the output data is a fixed-size vector.
   - Ex. Sentimental Analysis.

2. One-To-Many
   - ![[Pasted image 20251202150548.png]]
   - The input data is a standard format (not a sequence) but the output data is a sequence.
   - Ex. Image Captioning
   
3. Many-to-Many
   - ![[Pasted image 20251202150959.png]]
   - Both inputs and outputs are sequences which can be direct or lagged.
   - Ex. Video Captioning (Direct), Translating one language into another (Delayed.)
