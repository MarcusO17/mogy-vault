# Regularization

Regularization are methods to reduce overfitting on models. This is usually achieved by reducing model capacity or reduction of the prediction variance. In the context of deep learning, it can be understood as the process of adding information/ changing the objective function to prevent overfitting.

## Types of Regularization Methods
* [[Early Stopping]]
* [[L1 L2 Regularization|L1/L2 Regularization]]
* Dropout
