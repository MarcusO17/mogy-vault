# Non-Linear Activation Functions

With [[Multilayer Perceptron|hidden layers]] and non-linear activation functions, we can model complex, nonlinear decision boundaries.

>[!note]- Note
> - No hidden layers + Non-linear activation function  = linear boundary
> - Hidden layers + linear activation function = linear boundary



1. [[Identity Function]] :- $\sigma(z)=z$

![[Pasted image 20250915132231.png]]

2. [[Sigmoid Function|Logistic (Sigmoid)]] :- $\sigma(z) = \frac{1}{1+e^{-z}}$

![[Pasted image 20250915132308.png]]

3. [[Tanh Function|Tanh/tanH]] :- $\frac{e^{z}-e^{-z}}{e^{z}+e^{-z}}$
