# ReLU Function
Rectified Linear Unit

$$\sigma'(z)= \begin{cases}
0  & \text{if } z <0 \\
1  & \text{if } z > 0 \\
DNE  & \text{if }z = 0
\end{cases}$$
But for ML and DL , it is more convenient to say
$$
\sigma'(z)= \begin{cases}
0  &\text{if } z \le 0 \\
z  &  \text{if } z > 0
\end{cases}
$$
